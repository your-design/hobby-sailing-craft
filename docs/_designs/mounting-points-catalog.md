# OSEP-16 Mounting Points & Accessories Catalog

## Mounting Point System Overview

After hull panels are cut, sealed, and fiberglassed, we install standardized mounting points that accept various accessories for the three use cases:

1. **Solo Fishing**
2. **Family Day Sailing**
3. **Expedition Camping**

---

## Mounting Point Types

### Type A: Deck Track (T-Track System)
- **Location:** Sheer line, both sides of main hull and ama
- **Specification:** Aluminum T-track, 1/4-20 threaded
- **Length:** Continuous runs (6-8 feet per side)
- **Purpose:** Adjustable mounting for rod holders, rails, cleats

### Type B: Through-Bolt Hardpoints
- **Location:** Bulkhead intersections, pylon mounts
- **Specification:** Stainless steel backing plates, 5/16" bolts
- **Purpose:** High-load items (crossbeams, mast step, anchor point)

### Type C: Pad Eyes (Fixed Points)
- **Location:** Bow, stern, ama deck
- **Specification:** 1/4" stainless steel welded eyes
- **Purpose:** Tie-downs, safety lines, painter attachment

### Type D: Recessed Mounts (Flush Deck)
- **Location:** Trampoline frame, ama deck
- **Specification:** Countersunk stainless, gasket-sealed
- **Purpose:** Electronics mounts, cup holders, small accessories

## Installation Sequence

### During Hull Construction (Before Fiberglassing)

**Step 1:** Install Type B hardpoints
- Drill holes through hull + bulkhead
- Insert stainless bolts with backing plates
- Seal with epoxy before glassing over
- **Critical:** These can't be added later!

### After Fiberglassing (Before Launch)

**Step 2:** Install Type A tracks
- Mark centerline and offset lines
- Drill pilot holes through fiberglass
- Bed tracks in marine sealant
- Through-bolt every 8-10 inches
- Seal fastener heads

**Step 3:** Install Type C pad eyes
- Mark locations per plan
- Drill holes
- Bed in sealant
- Through-bolt with backing plates
- Load-test before use

**Step 4:** Install Type D recessed mounts
- Cut recesses in deck (router or jigsaw)
- Test-fit mounts
- Bed in sealant
- Through-bolt or screw
- Seal all edges

### Before Each Outing (Configure for Use)

**Step 5:** Attach use-case specific accessories
- Slide accessories into Type A tracks
- Tighten track nuts
- Clip/bolt to Type C pad eyes
- Screw into Type D mounts
- **Change configuration in 15-20 minutes!**
