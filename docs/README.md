## 💧 WATERPROOFING - HOW 400 HOLES STAY DRY

### The 3-Layer System

**Your concern:** "How can 400 riveted holes be watertight?"

**Answer:** Wet-riveting technique (standard since 1920s)

**Layer 1:** Sealant between panels (3M 5200 bead along seam)  
**Layer 2:** Sealant around each rivet shaft (dab in hole before riveting)  
**Layer 3:** Sealant over rivet heads (final gasket)  

**Result:** 98%+ watertight with standard technique  
**After flood test touch-ups:** 100% watertight

**Proven by:**
- Grumman canoes (60+ years, millions sold)
- Boeing 747 fuel tanks (48,000 gallons, riveted & sealed)
- WWII landing craft (decades in saltwater)

## 📐 DESIGN PHILOSOPHY

### Hard-Chine Geometry

**What it means:** All flat panels, sharp edges (no curves)

**Why it's better for DIY:**
- ✅ Easy to CNC plasma cut
- ✅ Flat panels easier to rivet
- ✅ No expensive forming tools needed
- ✅ Strong structural design

**Performance:**
- Sharp chine creates turbulence = lateral resistance
- Just as fast as smooth curves
- More stable in waves
- **Proven:** Every aluminum fishing boat uses hard chines

---

### Asymmetric Proa Concept

**Traditional proa features:**
- Ama (outrigger) always on SAME side
- Hull is asymmetric (flat leeward, curved windward)
- Can sail both directions (reversible)

**Our simplified version:**
- Symmetric hard-chine hull (easier to build)
- Ama still on one side
- Chine turbulence replaces asymmetric shape

**Trade-off:** Slightly less efficient upwind, but MUCH easier to build

## 🔍 QUALITY CONTROL

### Critical Checkpoints

**After panel cutting:**
- [ ] All edges deburred
- [ ] No warping from plasma heat
- [ ] Panels labeled (port/starboard)

**During riveting:**
- [ ] Sealant squeeze-out visible
- [ ] Each rivet head flush
- [ ] Rivets don't spin when touched

**Flood test (CRITICAL):**
- [ ] Zero leaks after 24-hour water fill
- [ ] If 1-3% seep: touch up with sealant
- [ ] If >10% leak: re-rivet affected section

**Before launch:**
- [ ] All mounting hardware installed
- [ ] Safety equipment on board
- [ ] Hull rinsed (no metal dust)

- Wipe down
